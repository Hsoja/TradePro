# Architecture

TradePro is a static site generated by Astro. There is no server, database or API: every page is pre-rendered HTML, and live data is delivered by TradingView widgets running inside sandboxed iframes.

```
Browser
 ├── TradePro page (our origin: HTML, one CSS file, one JS module, fonts)
 │     ├── canvas: animated trend lines        (src/scripts/trend-field.ts)
 │     ├── tabs, chart switcher, clock, hours  (src/scripts/app.ts)
 │     └── <iframe sandbox> × N ──────────────▶ www.tradingview-widget.com (cross-origin)
 │                                                └── TradingView's own data and news
 └── nothing else: no analytics, no CDNs, no APIs
```

## Pages

| Route | Content |
| --- | --- |
| `/` | Top stories, exchange hours, market snapshot, top movers, heatmaps, economic calendar, market links |
| `/news/` | Top stories feed next to the upcoming economic calendar |
| `/markets/` | Market cards and a live quote board for every asset class |
| `/markets/[slug]/` | One page per market (indices, stocks, futures, crypto, commodities, forex): chart with symbol chips, latest headlines, quotes, heatmap or cross rates |
| `/chart/` | Full-size chart with symbol search |
| `/calendar/` | Economic calendar with a short reading guide |
| `/about/`, `/legal/`, `404` | Project information, disclaimer and privacy |

Market pages are generated from `src/data/markets.ts` with `getStaticPaths`, so adding a market means adding one entry there.

## Key modules

**`src/lib/tradingview.ts`**: builds widget URLs in the same format TradingView's loader script uses (`/embed-widget/<type>/?locale=en#<encoded JSON>`). It accepts only allow-listed widget types, validates every symbol against `EXCHANGE:TICKER`, and exposes presets (news timeline, advanced chart, heatmaps…) with the site's colours. The configuration travels in the URL hash, which browsers never send to servers.

**`src/components/TvWidget.astro`**: renders one widget iframe with a title, sandbox, referrer policy and lazy loading. It refuses to render any URL that isn't on TradingView's widget host. Widgets in hidden tabs use `data-src` and load only when their tab opens.

**`src/scripts/app.ts`**: progressive enhancement. Accessible tabs (arrow keys, Home, End), symbol chips that swap the chart, a UTC clock and the exchange-hours board. It only sets properties and attributes, never HTML, and re-checks every iframe URL before assigning it.

**`src/lib/sessions.ts`**: pure functions that decide whether an exchange is open from its local time zone and regular hours, and how long until it opens or closes. Holidays are deliberately out of scope and labelled as such.

**`src/scripts/trend-field.ts`**: the background. Six random-walk price lines scroll across a faint grid on a 2D canvas at 30 fps, with a pulsing dot at each line's leading edge. It caps the pixel ratio at 2, stops when the tab is hidden and draws a single still frame when the user prefers reduced motion.

## Design system

| Token | Value | Use |
| --- | --- | --- |
| Void | `#06070D` | Page background |
| Panel | `rgba(13, 15, 30, 0.82)` | Cards and widget frames, blurred over the animation |
| Accent | `#7B6CFF` | Actions, selected tabs, main trend line |
| Up / Down | `#2BD9A0` / `#FF5C7A` | Gains, losses, open and closed exchanges |
| Text / Muted | `#E9ECF8` / `#9097B8` | Body and secondary text |

Typefaces: **Schibsted Grotesk**, a grotesque designed for a news publisher, for all text, and **IBM Plex Mono** for times and tickers. Both are bundled locally through Fontsource.

## Decisions

- **Iframes instead of TradingView's script.** The official snippet loads JavaScript from `s3.tradingview.com` into the page. Building the iframe URL ourselves keeps third-party code off our origin and lets the CSP stay at `script-src 'self'`.
- **Static output.** A news portal that collects no data doesn't need a server, which removes most of the attack surface and makes hosting free.
- **No Three.js.** The previous 3D background shipped a large library for a decorative effect; a 2D canvas gives the same sense of motion at a fraction of the size.
- **One news feed.** TradingView's iframe news widget now always shows its editorial top stories and ignores per-market filters. Its newer filtered feed is a web component that runs TradingView's script on our page, so we keep the isolated top-stories feed rather than weaken the CSP.
- **Symbols that free widgets can show.** CME, NYMEX, COMEX, CBOT and CBOE data, plus TVC bond yields, are not licensed for free widgets. A test blocks those symbols so the site never shows empty rows.
